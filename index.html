自然文で検索

社内コード・商品コード・JANコード・商品名に加えて、船便名や出港日を文章の中に入れて検索できます。船便に紐づく商品・数量・倉庫到着日・販売予定も確認できます。

入力例 「ABC-123の在庫数は？」 「10001はどこに何個ある？」 「商品名○○の在庫を教えて」
質問を入力して「検索する」を押してください。

権限について

※ このPINは端末内の誤操作防止用です。本格的な社員ログイン機能は、将来データ共有を導入するときに追加します。
操作ガイド

マニュアル

分からない操作をキーワードで検索できます。 「棚卸」「CSV」「発注」「船積」など、短い言葉で検索するのがおすすめです。

すべての項目を表示しています。

1. ホーム画面・表示モード・権限
  1. ホーム画面から、使いたい機能のボタンを押します。
  2. 右上の「表示・権限設定」から、PC表示・スマホ表示・管理者・作業者を切り替えます。
  3. 作業者モードでは、商品削除や数量調整など一部の管理操作が非表示になります。
  4. 画面右上の「画面版 v○○」で、更新後のバージョンを確認できます。
2. 商品一覧・在庫を検索する
  1. ホームの「商品一覧」から登録済み商品を確認します。
  2. 社内コード・商品コード・JANコード・商品名などで商品を絞り込めます。
  3. ホーム上部の文章検索では、「KW-251BKの在庫数は？」のように入力できます。
  4. 検索結果では、合計在庫と本社・酒本倉庫などの場所別在庫を確認できます。
3. 入庫・出庫・在庫履歴
  1. 商品一覧から対象商品を開きます。
  2. 商品詳細の「入庫する」または「出庫する」を押します。
  3. 数量・担当者・理由などを入力して確定します。
  4. 「在庫履歴を見る」から、その商品の在庫の動きを確認できます。
  5. 在庫数を直接修正する場合は、管理者モードの「数量調整する」を使用します。
4. 棚卸をする
  1. 特定の商品だけ在庫を再確認するときは、ホームの「商品単体の在庫確認」を使います。当日の出荷終了後、販売実績CSVを反映してから数えるのがおすすめです。
  2. 通常の棚卸は、ホームの「棚卸を開始する」を押します。
  3. 棚卸する場所と担当者などを設定します。
  4. バーコード読み取り、または手入力で商品を呼び出します。
  5. 実際に数えた数量を入力します。
  6. 未確認商品を確認してから棚卸を確定します。
  7. 必要に応じて棚卸結果CSVや集約機能を使用します。

棚卸場所が確定している画面では、場所欄を省略して数量入力を大きく表示します。

5. 販売予定を登録・確認する
  1. ホームの「販売予定を登録する」を開きます。
  2. 取引先名・副題・出荷日または出荷期間を入力します。
  3. 社内コードや商品コードから商品を呼び出し、数量を入力します。
  4. 同じ取引先・同じ出荷期間の商品は、複数商品をまとめて登録できます。
  5. 「販売予定一覧を見る」から登録内容を確認・編集・印刷できます。
6. 販売実績CSV・通常出荷数量
  1. ホームの「販売実績CSVを読み込む」から販売実績を取り込みます。
  2. 「通常出荷数量を見る」を開くと、前月までの直近6か月を集計します。
  3. 通常出荷数量の表示はこれまでどおり販売予定との照合結果を確認できます。
  4. 発注判定・出荷低迷・船積・ホーム検索の月平均は、「株式会社 後藤」「清水産業 株式会社」の販売実績を除外して6か月平均を計算します。
  5. 「季節変動商品一覧」では、春・夏・秋・冬ごとの月平均を比較し、増えやすい商品・減りやすい商品を確認できます。

出荷済みの販売予定を削除すると照合できなくなるため、基本的に履歴として残します。

7. 発注が必要な商品・発注残・追加発注
  1. 「発注が必要な商品一覧」で不足候補を確認します。
  2. 発注済み数量は「発注残」として管理し、現在庫とは分けて扱います。
  3. 仕入先へ追加発注した場合は、商品詳細の「追加発注する」から数量を入力します。
  4. 追加発注を登録すると、現在庫は変えず、発注残だけが増えます。
  5. 発注残の変更は「発注残一覧・編集」の変更履歴で確認できます。
  6. 商品が入荷したときは、入荷数量に応じて発注残を減らします。
8. 船便スケジュール・船積リスト
  1. 「船便スケジュールを登録する」から出港日・入港日・倉庫到着日などを登録します。
  2. 「船便別に商品を振り分ける」で、対象商品と船積数量を設定します。
  3. 「船積リストを倉庫へ振り分ける」で、各倉庫への数量を編集します。
  4. 必要に応じて船積リストや倉庫振分け内容を印刷します。
  5. 船便の入荷反映は、倉庫到着日を基準に処理します。
9. 商品を倉庫・本社間で移動する
  1. 商品移動の画面で、移動元・移動先・商品・移動数量を設定します。
  2. 移動内容を確認して確定します。
  3. 必要に応じて移動リストを印刷し、移動元・移動先の確認に使用します。
10. 加工・商品切替の記入シートを印刷する
  1. ホームの「入出庫・履歴」から「加工・商品切替 記入シート」を開きます。
  2. 画面で用紙の内容を確認し、「B5で印刷する」を押します。
  3. 作業場では、加工元A・加工後B・使用数量・完成数量・担当者などを手書きします。
  4. 作業後は用紙を在庫管理担当者へ提出し、在庫反映後に確認欄へ記入します。

印刷はB5縦1枚を想定しています。プリンター側でも用紙サイズがB5になっていることを確認してください。

11. バーコードを印刷する
  1. ホームの「バーコードを印刷する」を開きます。
  2. 商品を検索して、印刷対象へ追加します。
  3. 社内コード・JANコード、A4の分割数、ラベル枚数を設定します。
  4. 「選択したバーコードを印刷する」で印刷画面を開きます。
12. CSV・バックアップ・復元
  1. 商品一覧・入出庫履歴・棚卸結果などはCSVで出力できます。
  2. 商品データを一括登録するときはCSV読込を使用し、プレビューとエラーを確認します。
  3. アプリ全体のデータを保存するときは「バックアップ」を使用します。
  4. 別端末や復旧時は、対応するバックアップファイルを選んで復元します。

大きな変更やCSV更新の前には、先にバックアップを取るのがおすすめです。

13. スマホ・PWA・画面更新
  1. 対応端末ではホーム画面へ追加して、アプリのように起動できます。
  2. 更新後は画面右上のバージョン番号を確認します。
  3. PCで古い画面が残る場合は、Ctrlキーを押しながらF5キーを押して再読み込みします。
  4. スマホ表示では、棚卸や商品確認をしやすい画面構成になります。

通常出荷数量

販売実績CSVの出荷数量から、販売予定として登録していた出荷分を除いた「通常出荷数量」を確認できます。
月平均の計算は別ルールで、「株式会社 後藤」「清水産業 株式会社」の販売実績を除外した数量を使用します。

通常出荷数量を計算します。
計算方法
通常出荷数量 ＝ 総出荷数量（返品差引後）－ 販売予定として照合できた数量
販売予定は「同じ商品・同じ取引先・出荷日または出荷期間」が一致した実績と照合します。
取引先名の「株式会社」などの表記差や空白は無視して照合します。
月平均の計算：前月までの直近6か月の販売実績から「株式会社 後藤」「清水産業 株式会社」を除外し、残った数量 ÷ 6（端数切り上げ）です。
注意：この画面の「通常出荷数量」は販売予定との照合結果を確認するための表示として残しています。

船便別に商品を振り分ける

船便を選択すると、今回の倉庫到着日から次便の倉庫到着日前日までに必要な商品を自動計算します。
船積対象は、仕入先が「株式会社モービック」の商品のみです。
専用商品は船積振り分け対象外のため、この一覧には表示しません。
対象期間は「今回の倉庫到着日 ～ 次便の倉庫到着日前日」です。
期間販売見込 ＝ 直前6か月の月平均販売数 ÷ 30日 × 対象日数（小数切り上げ）。
月平均販売数は「株式会社 後藤」「清水産業 株式会社」の販売実績を除外して計算します。
推奨数量 ＝ 「期間販売見込 ＋ 対象期間の販売予定数」－ 現在庫 － 前の船便への振分数量です。
未保存の商品は「今回の船便」を0個で表示します。実際に積む商品だけ数量を入力して保存してください。
推奨数量をそのまま使う場合は、各商品の「推奨を入れる」ボタンを押せます。

不足候補に表示されていない商品でも、 必要な商品を手動でこの船便へ追加できます。
廃盤商品・専用商品・船積対象外の仕入先の商品は追加できません。
