# v294.1 Amazon準備用とピッキング・パッキング用

管理者が「端末内の従来機能を使う」を選ぶと、ホームの「販売・実績」から「Amazon準備用」と「Amazonピッキング・パッキング用」を開けます。

- C列：配送センター／配送先、E列：JAN（製品コード）、N列：依頼数量／数量。先頭に見出しが必要。
- UTF-8（BOMあり／なし）とShift_JISに対応。文字化けするときは文字コードを選び直す。
- 商品別はJANごとの依頼数量合計、配送先別は配送先合計と配送先・JAN別の内訳。どちらも印刷可能。
- 在庫・販売予定は「この端末」の取得時点のデータ。共有サーバーからの自動取得ではない。
- JANは文字列で照合。8桁／13桁とチェック桁を確認。指数表記、末尾に0が6桁以上続く値は要確認に分ける。後者は丸めの可能性を検知する保守的な確認であり、JANが必ず誤りだという判定ではない。
- 要確認行は商品別集計と在庫照合から除外し、元の行のまま表示。数量を確認できる行は配送先合計には含める。数量不明行は個数の合計に含めず、総数量未確定の表示を出す。
- 同JANの商品が複数ある在庫は、商品単位の総在庫が最大のものを採用。別商品の重複在庫を加算しない。重複のいずれかに在庫数不明があれば最大値を確定せず要確認とする。
- 同JANのいずれかの商品の社内コードに販売予定が登録されていれば黄色と「販売予定あり」。登録済みの全予定（過去分を含む）が対象。予定数量を現在庫から差し引かない。
- 現在庫が全配送先のAmazon必要数より少なければ、現在庫の数値を赤字にし「在庫不足」と不足数を併記。未登録・在庫数不明と0個を区別する。
- 配送先別の在庫欄は全体在庫の参考表示。各配送先への在庫割当・配送先ごとの引当可能数ではない。全配送先必要数も併記し、不足判定は全体需要に対して行う。
- 配送先別では「表示・印刷する配送先」で1件または全件を選択できる。要確認明細と数量合計も選択範囲に絞る。商品別に切り替えるとCSV全体を表示する。在庫不足は絞り込みにかかわらず全配送先の必要数で判定する。
- CSVを読み直すと集計は置き換わる。「現在庫・販売予定を再取得」で端末の最新情報と再照合する。画面を閉じるとCSVを再選択する必要がある。
- 「架空データで試す」は画面内だけのデモ。在庫・予定・CSVの保存やサーバー送信は行わない。

## Amazonピッキング・パッキング用

ホーム → 販売・実績 → Amazonピッキング・パッキング用。Amazonから取得したPickListを選びます。PO・配送センター・ASIN・JAN・モデル番号・商品コード・受領待ちのケースを明細ごとに表示します。元の行順とPOごとの明細を保ちます。

配送センターを選ぶと、表示・印刷・作業用CSV・Excelがその配送センターに絞られます。ピッキング確認・パッキング確認の空欄を作業に使えます。数量はPickListの「受領待ちのケース」を使用します。入力に不備がある場合は該当明細を示し、修正後にCSVを読み直します。

「作業用Excelを出力する」で、JANやモデル番号を文字列として保存した .xlsx を開けます。ケース数は数値です。出力CSVはUTF-8 BOM付きです。先頭に0があるJANをExcelで扱う場合は、CSVの取り込み時にJANコード列を文字列として指定します。

## 商品コード表示の確認版

ピッキング・パッキング一覧の「商品名」列を「商品コード」に変更。JANでこの端末の商品マスタを照合し、商品コードが一意なら採用します。同JANで異なるコードが複数ある場合は要確認です。マスタにコードがない場合のみAmazonのモデル番号を使用します。数字だけ、JANと同じ、空欄のモデル番号は商品コードとして扱いません。画面・印刷・CSV・Excelは同じ照合結果を使います。PO・明細順・ケース数は保持し、在庫数や商品マスタは更新しません。

商品マスタはCSV選択時点のものです。商品マスタを変更した場合はCSVを再選択してください。読込に失敗した場合は出力しません。

準備用も商品別・配送先別・印刷・要確認明細の商品名列を商品コード表示に統一。JAN照合とモデル番号への代替はピッキング用と共通です。同JANのモデル番号が行ごとに異なる場合は要確認とし、集計数量・在庫の最大値採用・販売予定表示は維持します。

ピッキング用の配送センター表示は、先頭の英数字4文字と区切りが確認できる場合に4文字のみを表示します。画面・選択肢・印刷・Excel・CSVが対象です。絞り込みには元の配送先情報を保持し、PO明細を統合しません。準備用の配送先も選択肢・集計画面・印刷で先頭の英数字4文字を表示します。元の配送先情報は絞り込みと集計に保持します。

ピッキング・パッキング用の出力列は、PO・配送センター・JANコード・商品コード・受領待ちのケース・ピッキング確認・パッキング確認の7列です。画面・印刷・Excel・CSVで共通とし、ASINとモデル番号の列は出しません。元CSVのモデル番号は商品コード補完のため読み込みを維持します。

ピッキング・パッキング用は配送先ごとに見出し・明細数・ケース数と表を分けます。画面と印刷で共通です。Excelは配送先の切り替わりに空行を挿入し、CSVは7列のまま配送先ごとに明細を並べます。配送先は元の値でグループ化し、CSVで最初に登場した順に表示します。PO明細と数量は合算しません。

ピッキング・パッキング用はA4縦向きで印刷します。7列の幅を固定し、長い商品コードは折り返します。Amazon準備用の印刷はA4横向きを維持します。

同JANに異なる商品コードがある場合、すべての候補の在庫数が有効なら、最大在庫の商品のコードを使用します。最大在庫が同数かつ異なるコードの場合や、候補に在庫数不明が含まれる場合は要確認を維持します。準備用・ピッキング用で共通です。在庫数やマスタの保存は行いません。

ピッキング用の「受領待ちのケース」見出しを「ピッキング数」に変更し、右隣に「在庫数」を追加します。CSV読込時の端末の商品マスタから、同JANの最大在庫数を表示します。同数の場合はその数量を表示し、合算・引当・出庫はしません。未登録は「未登録」、候補に無効な在庫数がある場合は「在庫数不明」とします。画面・印刷・Excel・CSVの8列で共通です。元のAmazon CSVの入力列名は変更しません。
