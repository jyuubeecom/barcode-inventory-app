# v294.5 共有商品の作業者向け操作表示

共有商品の詳細画面で、作業者に「商品情報を編集する」「数量調整する」が表示され、押すと管理者専用の案内が出ていた。

作業者では両ボタンを非表示にし、説明も入庫・出庫・履歴確認の範囲に合わせる。管理者に戻したときはボタンと説明を復帰する。詳細画面を開くたび、および権限モードの変更時に適用する。権限が未取得の場合、管理操作は非表示にする。

既存の操作時の権限制限は維持する。入庫・出庫・在庫履歴および保存データの仕様は変更しない。

## 確認

- 自動テストで作業者の非表示、管理者への復帰、説明文、入出庫・履歴の表示維持、権限未取得を確認。
- 既存の自動テストも実行。
- ブラウザ表示の自動確認は、環境にChromium実行ファイルがないため未実施。
- 公開後は作業者でTEST-P001の詳細を開き、2ボタンが非表示で、入庫・出庫・履歴が表示されることを確認する。管理者に戻して2ボタンの再表示を確認する。数量の変更は不要。
