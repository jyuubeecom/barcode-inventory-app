# v293.14 起動時ログイン

共通データの画面を未ログインで起動すると、最初にログイン画面を表示します。ログイン成功後はホームへ進み、確認用商品の自動検索は行いません。既存のログインAPIとタブ内のセッションを利用します。

有効期限内のログイン状態が残っていれば、そのまま利用できます。期限切れは期限タイマー、アプリへ戻ったとき、既存APIの認証切れ通知で確認します。通信時の権限判定は従来どおりサーバーで行います。端末内の従来機能を管理者が選んでいる場合は、起動時ログインの対象外です。

ログイン画面の表示中は背景の操作を止め、閉じるボタンやEscapeでホームへ抜けないようにします。管理者・作業者とも同じログイン画面を使えます。ホームのログアウトでログイン画面へ戻ります。パスワードや在庫データの保存方式は変更しません。

検証版では未ログイン起動、ログイン成功後のホーム、ログアウト、再起動、作業者モードでのログインを確認してください。ログイン失敗・セッション保存失敗・期限切れ・従来機能の動作を架空データの自動テストで検証しています。PCとスマートフォンの実画面確認後に、本番反映の承認を得ます。
