# v295.1 保存済み棚卸結果の確認

共有棚卸を開くと「保存済みの結果を確認」ボタンを表示する。
押すたびに既存の共有棚卸GET APIから全対象の保存済み数量を読み直し、対象商品・確認済み・未確認・差異なし・在庫不足・在庫過剰の件数を表示する。

空欄（null）は未確認で、0個は確認済み。未確認は差異なし・不足・過剰のいずれにも加えない。
商品検索や絞り込みには影響されず、棚卸全体を対象とする。登録在庫は棚卸開始時点の値を使う。
未保存の入力を保存済みの結果に混ぜず、入力自体は破棄しない。未保存件数を併記する。
取得に失敗した場合は前の集計を非表示にし、エラーを表示する。棚卸を切り替えたとき・数量保存後・ログイン状態が変わったときも前の集計を消す。

変更ファイルはshared-stocktaking.js・index.html・service-worker.jsと検証ファイル。サーバーPHP・SQL・DBの追加変更は不要。
棚卸確定・現在庫への反映は引き続き次の段階とする。本番の在庫データや棚卸データを変更するテストは実施しない。

検証：件数の分類・0個・未確認・異常な応答の拒否をNodeで確認。
全外部通信を架空応答に置き換えた実ブラウザでは、スマホ390pxで集計表示、未保存入力の保持、POSTが増えないこと、再取得失敗時に前の集計が残らないことを確認する。

反映後の操作：共有棚卸の「棚卸を開始・再開」→保存済み棚卸を再開→「保存済みの結果を確認」。
正常時は6種類の件数が表示される。読込エラー時は再ログイン・接続状態を確認して、同じボタンで再取得する。
本番でテスト用の棚卸を作る必要はない。公開はユーザーの反映承認後に行う。
