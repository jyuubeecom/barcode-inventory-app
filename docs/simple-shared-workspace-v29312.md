# v293.12 共通在庫のシンプル表示（移行の第1段階）

初期画面は商品一覧・現在庫表の2つの入口に絞り、共有データを直接開く。入庫・出庫は商品詳細の既存操作を使う。通常画面に保存先の選択肢を出さない。

共通モードでは、端末内のホーム集計・自然文検索・要確認アラート・未接続メニューを表示しない。端末内の数量を共有在庫として見せず、通信失敗時の端末内データへの切り替えもしない。従来機能は管理者設定の「端末内の従来機能」から開く。作業者は管理者の従来モード設定が残っていても共通モードを使う。これは画面上の案内であり、サーバーAPIの権限は引き続きサーバーが検証する。

## 保存と境界

- DB・商品・数量・履歴を合算、削除、上書きしない。表示モードだけを端末設定に保存する。
- モード変更はホームへ戻り、取得中の応答を無効化し、表示条件をリセットする。
- 検証用DBとアプリIDはv293.11から維持。本番のDB・アプリIDも変更しない。
- 通信失敗時は取得不能と表示する。オフライン閲覧用の共通データ保存は未実装。過去の数量を最新として表示しない。

## 統合が残る機能

棚卸、通常の販売実績、販売予定、加工、移動、発注・船便判断、自然文検索、ケース割れは従来データを使っている。これらの共有接続を完了してから、共通モードへ順次追加する。この段階で全機能の統合完了とはしない。

## 検証

Nodeで共通データの初期選択、端末内への切り替え抑止、取得失敗・ログアウトでの混在防止、管理者の明示切り替え、作業者制限、保存領域エラーを検証。既存の入出庫・在庫表・PWA分離テストも実行する。

この環境にブラウザー実行ファイルがないため、PC・スマートフォンの最終画面確認は検証ZIPで行う。本番公開はその確認後、ユーザー承認を得て行う。
