# v293.10 現在庫表の全項目表示（検証版・修正版）

現在庫表を横スクロールせずに確認したいという要望に合わせ、左右ボタンと固定列方式を画面幅に収まる表示に置き換えた。

- PCは8項目（No、保管場所、社内コード、商品コード、商品名、色、現在庫、商品状態）を幅100%の表で表示。
- 長い商品名・コード・場所・色・状態は省略や切り捨てをせず折り返す。
- 表の領域が720px以下、または画面幅が760px以下の場合は項目名付きカードに切り替える。全項目を保持し、表示行は縦に並ぶ。
- 左右ボタン、固定列、横スクロールの最小幅指定は削除。
- 在庫取得・数量・検索・保管場所フィルター・従来の印刷処理、DB、API、バックアップ形式は維持。
- Amazon CSV集計とは別の変更で、本番mainには未反映。

既存機能のNode自動テスト107件、構文・空白チェック成功。PCと狭い画面の実表示は確認待ち。

03-scroll-demo/index.htmlは実在庫を使用せず試せる専用画面。架空在庫は12個・34個・56個、合計102個。実在庫の保存・外部送信は行わない。
